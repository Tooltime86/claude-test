# Claude MCP Test

## About

This repository demonstrates GitHub MCP (Model Context Protocol) tools integration with AI assistants.

## Getting Started

To enable GitHub MCP tools for AI assistant integration, please refer to the [GitHub MCP Setup Guide](GITHUB_MCP_SETUP.md).

## Quick Start

1. Enable GitHub integration in your AI assistant interface
2. Connect and authorize your GitHub account
3. Configure MCP settings using the example configuration
4. Start using AI-assisted GitHub operations

## Documentation

- [GitHub MCP Setup Guide](GITHUB_MCP_SETUP.md) - Comprehensive setup instructions
- [MCP Configuration Example](mcp_config_example.json) - Example configuration file
- [GitHub Tools Demo](github_tools_demo.py) - Example Python script demonstrating MCP usage

## Features

With GitHub MCP tools enabled, you can:
- ✅ Browse GitHub repositories through AI
- ✅ Read files from GitHub
- ✅ Create files in GitHub repositories
- ✅ Commit and push changes
- ✅ Access repository metadata and history

## Requirements

- GitHub account with appropriate permissions
- AI assistant with MCP tools support
- GitHub personal access token (for authentication)

## Security

Please review the security considerations in the [setup guide](GITHUB_MCP_SETUP.md) before enabling GitHub MCP tools.
